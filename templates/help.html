SubLive

Multilingual live subtitle operator — documentation

Quick start

  1. docker compose up --build
  2. Open http://localhost:8000
  3. Click ▣ Scr1/2/3 to open display windows
  4. Drag each window to an external monitor → F11 for fullscreen
URLContent
/display/0Language 1 — also to YouTube
/display/1Language 2 (or combined L2+L3)
/display/2Language 3

Shortcuts are blocked while typing in a text field (except in Show mode).

Cue table

One row per cue, three columns for languages. Click a row to fire it. Row controls: off/en disables/enables, ✕ deletes. When multiple rows are selected, clicking off or ✕ on any selected row applies to the entire selection (with confirmation).

Cue numbering

Free text: 1, 1.1, 4.5, 10a. + After current inserts the next integer. ⟳ Renumber resets all to 1, 2, 3…

Multi-select

Shift+click range-selects from the last-clicked row to that one. Cmd+A selects all. Drag any selected row to move the whole selection. The add-row toolbar has batch buttons: Group sel., Select all, Disable sel., Delete sel.

Groups

Collapsible folders. Collapsed groups are skipped during playback. ⊞ selects all cues inside. + adds a cue inside. Drag cues onto a group row to move them inside.

Show mode

Click ▶ Show mode. An amber bar appears below the topbar. Sidebar and add-row are locked. Text editing disabled — clicking a row fires it. Multi-select off. Drag off. Record and all transport shortcuts still work.

Workflow: prepare → ▶ Show mode → ⏺ Record → fire cues → ↓ SRTs.

Display screens

Each screen button opens a new browser window. Drag to external monitor → F11. Enable Combine Scr 2+3 to stack L2 and L3 on Screen 2.

SRT recording

  1. ⏺ Record before the show
  2. Fire cues — each is time-stamped
  3. ⏹ Stop rec at the end
  4. ↓ L1 / L2 / L3 to download

Empty cues are skipped. Minimum duration 0.5s.

LTC timecode

Enable Lock to LTC. Connect LTC source to audio input (line level). Select device + frame rate. Watch the meter — aim for green (40–70%).

IndicatorMeaning
Purple SYNCEDDecoding correctly, SRT uses LTC time
Orange FREEWHEELSignal lost, holds 2 s then stops
Line level input required. Disable echo cancellation and AGC. Decoder verified against 48kHz 16-bit 25fps LTC signal.

YouTube captions

YouTube Studio → Go Live → Edit stream → Advanced → Closed captions → POST captions to URL → copy URL → paste in sidebar → check Send L1 → Test.

POST format

Body: 2024-01-15T14:23:45.123\nCaption text\n — timestamp on first line, text on second, both required. Content-Type: text/plain. &seq=N parameter increments automatically.

Get a fresh ingestion URL from YouTube Studio for each broadcast.

Display format

Three fonts: Sans-serif, Serif, Monospace. Adjust size, bold, italic, color per language. Apply to all 3 copies the style to all languages.

Projects

↓ Project downloads a .sublive file. ↑ Project opens one from your machine. Ctrl+S downloads. The • in the name means unsaved changes.

Performance — 500+ cues, 5h+ sessions

  • Use groups — collapsed groups reduce DOM count significantly
  • Enter Show mode before the show — disables event listeners for drag/edit
  • WebSocket messages are <300 bytes per cue send regardless of cue count
  • Server holds cues in memory — no I/O on each fire
  • Use LTC for SRT time to avoid clock drift on long sessions
